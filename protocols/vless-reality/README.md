# VLESS + Reality via 3x-ui

## Image
`ghcr.io/azumi67/3x-ui:latest`

- **Source:** https://github.com/MHSanaei/3x-ui
- **Tag policy:** `latest` tracks upstream releases. Pin to a digest hash in production if deterministic builds are required.
- **Built-in UI:** Yes — 3x-ui Web panel on mapped `XUI_PORT` (default 2053).

## Default Credentials
- **Username:** `admin` (configurable via `ADMIN_USERNAME` in `.env`)
- **Password:** Set via `ADMIN_PASSWORD` in `.env`. Displayed once after `setup.py` completes.
- **First run:** Log into `http://<VPN_HOST>:<XUI_PORT>`, change password immediately.

## Post-Deployment Setup (Manual via Web UI)
1. Log into the 3x-ui panel.
2. Navigate to **Inbounds** → **Add Inbound**.
3. Import the rendered `config.template` (or configure manually):
   - Protocol: `vless`
   - Port: `${VLESS_PORT}`
   - Stream Security: `reality`
   - Fill in Reality keys (auto-generated by setup.py or the panel's built-in key generator).
4. Add a client user (UUID auto-generated by the panel).
5. Share the generated VLESS link or QR code from the panel.

## DPI Evasion Status (Russia 2026)
| Capability            | Status                                              |
|-----------------------|-----------------------------------------------------|
| Protocol fingerprint  | **Excellent** — VLESS has no distinctive handshake  |
| TLS fingerprint       | **Excellent** — Reality uses real TLS server certs   |
| SNI-based blocking    | **Bypassed** — Reality uses the dest site's real SNI |
| Active probing        | **Mitigated** — Reality requires matching shortId    |
| Port-based blocking   | Mitigated by using non-standard `VLESS_PORT`         |

**Recommendation:** This is the **primary recommended protocol** for restrictive network environments. The Reality transport makes Xray traffic indistinguishable from regular TLS to `REALITY_DEST`. No long-term keys are exposed on the wire.

## Security Notes
- Reality private key is generated once and stored in `.env`. Rotate if compromised.
- The 3x-ui panel is served over **HTTP** by default. Place behind a reverse proxy with TLS or restrict to localhost with SSH tunneling for production.
- `config.template` is a convenience import. All Reality parameters, including keys and shortIds, can also be configured through the Web UI directly.
- The `REALITY_DEST` domain should be a major CDN-backed site (e.g., `www.microsoft.com:443`) to blend with high-volume traffic.
